Calling the feed from an agent

The usual advice applies: ask only for what you will use, cache for a few seconds and back off on retries so you do not hammer the API. 

GET /v1/quote?pair=XLM/USDC
Accept: application/json

More feeds now charge per request. The first call answers with a price, your agent pays a few cents in USDC and repeats the call with the payment attached. Give the agent a small budget and log every payment it makes.

Performance basics

Back to the technical side: set a sensible timeout, respect status codes and keep a log of every request so you can debug later. Nothing exotic, but it makes a real difference in production.
